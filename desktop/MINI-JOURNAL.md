# SYTER 1.1.0 — мини-журнал для Windows

## Установка

1. Завершите старый SYTER через меню значка возле часов → «Выход».
2. Запустите `SYTER-Setup-1.1.0.exe`. Он обновит существующее приложение.
3. Войдите в журнал и дождитесь загрузки аккаунта.
4. Нажмите правой кнопкой на значок SYTER возле часов → **Мини-журнал**.

Сайт отдельно публиковать не требуется: интерфейс мини-журнала включён
в установщик и подключается только в десктопной версии. Предыдущие
исправления аккаунтов на уже опубликованном сайте продолжают работать.

## Использование

- В TradingView выберите **Копировать изображение**, затем нажмите Ctrl+V
  в мини-журнале. Или нажмите «Вставить · Ctrl+V» в самой панели.
- Скачанное изображение можно выбрать через Choose file или перетащить
  в форму. Ссылки на изображения не обрабатываются.
- Галочка «Подхватывать изображения» работает, только пока мини-журнал
  открыт на экране. В полном журнале, в трее и в свёрнутом окне буфер
  обмена не читается, а скриншоты, сделанные в это время, не подхватываются.
- Заполните обычные поля сделки; при желании добавьте комментарий.
- Кнопка «Закреплено / Закрепить» управляет отображением поверх других окон.
- За чёрную верхнюю полосу окно можно перетаскивать; за края — менять размер.
- «Развернуть ↗» возвращает полный журнал. Это та же страница: поля,
  комментарий и изображение сохраняются при переключении режимов.
- В полной форме добавления сделки есть кнопка «Мини-журнал ↗».
- Ctrl + Shift + Ё переключает режим. Удержание клавиш срабатывает один раз;
  из трея или свёрнутого окна сочетание открывает именно мини-журнал.
- Крестик окна прячет приложение в трей вместе с текущим черновиком.
- Размер и положение панели запоминаются отдельно от полного окна.
- При успешной записи форма готова к следующей сделке. При отказе сервера
  черновик остаётся. Повторная попытка использует тот же идентификатор сделки.

Черновик сохраняется при переключении режимов и скрытии в трей, пока
приложение работает. Перезагрузка страницы, выход из аккаунта и завершение
приложения сбрасывают несохранённый черновик. Для работы требуется интернет.
Мини-журнал предназначен для обычных сделок; бэктесты остаются в полном окне.
Изображение подготавливается под лимит документа Firestore: длинная сторона
до 2274 пикселей, при необходимости размер/качество дополнительно уменьшаются.

## Обновление через GitHub

Архив `SYTER-1.1.0-GitHub-release.zip` содержит ровно три файла обновления:

- `SYTER-Setup-1.1.0.exe`
- `SYTER-Setup-1.1.0.exe.blockmap`
- `latest.yml`

Распакуйте архив и прикрепите **эти три файла** к новому обычному release
с тегом `v1.1.0` в репозитории `mishakozlov723-wq/syter-releases`.
Прикреплять только ZIP вместо трёх файлов не нужно: автообновлению нужен
доступ к `latest.yml` и установщику. Здесь release не публиковался.

## Исходники и сборка

`TJ-desktop-mini-source.zip` содержит папку `desktop` с обновлёнными
исходниками и ресурсами. Распакуйте в корень существующего TradingJournal
с заменой файлов. Данные журнала и файлы сайта не изменяются.

```sh
cd desktop
npm ci
npm run build
```

Версия уже установлена в 1.1.0, поэтому `npm run release` для этой сборки
не нужен: он дополнительно увеличивает номер версии.

Если установленный Electron уже находится в `node_modules/electron/dist`,
можно собрать без повторной загрузки его дистрибутива:

```sh
node node_modules/electron-builder/cli.js --win nsis --x64 --publish never --config.electronDist=node_modules/electron/dist
node scripts/publish-update.js
```

## Проверка

Проверено в реальном Electron 38: меню трея, изменение размера окна,
закрепление, скрытие/возврат, вставка изображения событием paste и через
Electron IPC, выбор файла, удаление картинки, неверный формат, сохранение
черновика при разворачивании, отказ записи и повтор с тем же ID, успешная
запись, смена аккаунта и отдельная форма бэктестов.

При проверке использовался отдельный профиль приложения, тестовые данные
и имитация Firestore. Рабочая база не изменялась; буфер пользователя не
перезаписывался. Проверка на реальном аккаунте после установки остаётся
за пользователем.

Автотест: `tests/mini-journal.e2e.cjs`. Ему требуется Playwright в окружении
(можно указать путь к модулю через `SYTER_PLAYWRIGHT_MODULE`), установленный
Electron и соседняя папка `public` из проекта. Пример запуска из desktop:

```sh
node tests/mini-journal.e2e.cjs
```

Можно передать путь к PNG вторым аргументом команды вместо тестового значка.
Результаты и отдельные профили теста пишутся в `desktop/test-output`.
