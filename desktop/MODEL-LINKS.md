# Описания моделей в desktop-версии

Ссылки на описания моделей — это общие страницы Notes журнала
с параметром `?note=...`. При нажатии они открываются в браузере,
выбранном в Windows по умолчанию.

Окно SYTER не переходит на страницу описания и не создаёт второе
Electron-окно. Текущий экран и несохранённая форма остаются на месте.
Обычная навигация по журналу и локальная страница ошибки подключения
продолжают работать внутри приложения.

Проверки охватывают ссылки с новой вкладкой и переход в текущей вкладке,
оба домена Firebase, обычные страницы журнала и запрещённые протоколы:

```sh
cd desktop
npm test
```

Это desktop-правка. Она появится у пользователей только после сборки
и установки новой версии приложения. Публикация релиза выполняется отдельно.
