SYTER: локальный тест настоящего обновления 1.3.6 -> 1.3.7

1. У тебя должна быть установлена версия 1.3.6 из предыдущего сообщения.
2. Закрой SYTER через «Выход» в меню значка возле часов. Крестик только скрывает окно.
3. Распакуй ВЕСЬ ZIP в отдельную папку (не запускай из архива).
4. Дважды нажми START-TEST.cmd. Администратор не нужен. Окно консоли оставь открытым.
5. SYTER откроется. Примерно через 5 секунд появится фирменное предложение обновления.
6. Update now -> реальное скачивание -> Restart and install.
7. После перезапуска проверь журнал, вход и настройки. В консоли появится SUCCESS.

Не запускай SYTER-Setup-1.3.7.exe вручную: тогда будет переустановка, а не тест обновления.

Этот тест действительно заменяет установленную 1.3.6 на 1.3.7. Это НЕ отдельная копия приложения.
Он временно меняет только resources/app-update.yml, сохраняя оригинал в этой папке.
Ни сайт, ни основной GitHub-релиз не меняются. 1.3.7 ещё не опубликована для всех.
Локальный сервер доступен только на 127.0.0.1:51873, не из интернета или домашней сети.
Для видимых процентов скорость тестового сервера ограничена 8 МиБ/с; проценты настоящие.
Пароли и данные журнала скрипт не читает, не копирует и не удаляет.

Если нажал Later: загрузка и установка не начнутся. Для повторного предложения закрой
SYTER через «Выход» в трее, запусти его снова, оставив тестовую консоль открытой.

Не закрывай консоль посреди скачивания/обновления. Нормальная остановка — Ctrl+C.
Если закрыл консоль крестиком или компьютер перезагрузился: запусти
RESTORE-NORMAL-UPDATES.cmd, затем выйди из SYTER через трей и открой его обычно.
Не удаляй папку, пока источник обновлений не восстановлен.
После успешного теста не устанавливай 1.3.6 поверх 1.3.7. Дальнейшее обновление будет
отдельной более новой версией. Повтор этого ZIP после успеха намеренно блокируется.

Windows может показать собственное предупреждение о неподписанном приложении/скрипте.
Подпись и репутацию SmartScreen этот тест не создаёт.
